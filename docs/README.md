# docs/

- `preregistration/` — the analysis plans that were written and committed **before** the corresponding runs:
  - `sensitivity_sweep.md` — the 66-setting threshold sweep (Section V-B of the paper, Fig. 1);
  - `window_matching.md` — the matched-window control (Section V-A, Table III);
  - `confidence_intervals.md` — the moving-block bootstrap (Table IV).
  They are verbatim copies; file paths inside them refer to the project's earlier flat layout
  (e.g. `code/experiments.py` is now `experiments/grid.py`, `code/days.py` is `nids/days.py`).
- `history/` — notes from earlier phases (task list, Phase-1 summary, CICIDS2017 CSV evaluation notes). Kept for
  reference; the current instructions are in the main README.
